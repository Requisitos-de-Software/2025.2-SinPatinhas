### **HU032 – Mapa interativo**
*Autoria: Heloisa Silva*

| **Campo** | **Descrição** |
|------------|----------------|
| **Identificação** | HU032 |
| **Tema** | Mapa interativo |
| **Descrição** | Como *tutor que deseja procurar atendimento para meu pet*, desejo *poder visualizar em um mapa quais as clínicas próximas a minha localização* para *poder decidir qual a clínica mais apropriada para o atendimento*. |
| **Critérios de Aceitação** | - O sistema deve mostrar ao abrir mapa da região dentro de 10 km do usuário inicialmente <br> - Ao abrir o mapa a localização do usuário deve estar centralizada
| **Prioridade** | Média |
| **Status** | Não validada |
| **Rastreabilidade** | [RFNI001](../../../elicitacao/tecnicas_elicitacao/requisitos_elicitados.md#rfni001) |
| **Validação** | - |
